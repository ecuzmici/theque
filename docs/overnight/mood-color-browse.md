# Overnight idea: Mood / color browse mode

Status: **in progress** (stub marker — branch is not yet complete).

A dedicated `/palette` route that organizes the user's library by the
`dominant_hue` / `dominant_color` already extracted at enrichment time,
bucketing items into named palette "moods" (Reds & warms, Ambers & golds,
Greens, Blues, Purples & pinks, Neutrals & monochrome, plus a fallback for
items without a cover color). Tap a mood to filter.

This file flips to "complete" in the final commit so an interrupted branch is
visually distinguishable from a finished one.
