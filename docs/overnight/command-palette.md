# Overnight idea: Cmd-K command palette + global quick-add

Status: **complete**.

A global ⌘K / Ctrl-K command palette for the authenticated app:
- Jump to shelves (All · Books · Watch · Articles · Done) and pages (Search, Add, Settings).
- Paste a URL to save it instantly without leaving the page (reuses the `/api/capture` path).
- Keyboard-driven (arrow keys, Enter, Esc) and accessible (base-ui Dialog focus trap),
  with a visible touch affordance in the nav for mobile.

Retention lever: collapses capture + navigation friction to near zero.
